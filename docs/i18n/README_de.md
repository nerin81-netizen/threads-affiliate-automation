## 📌 Hauptfunktionen

1. **💬 Interaktions- & KI-Kommentarmotor (`scripts/rapport_engine.mjs`)**:
   - Versteht Social-Media-Slang und umgangssprachliche Tonalitäten.
   - Erzeugt 3 Kontext-Stile (Tiefes Mitgefühl, Witziger Dialog, Herzliche Unterstützung).
   - Automatische Keyword-Erkennung und sichere Interaktions-Pipeline.

2. **📦 30-Tage-Tresor mit 100 Spitzeninhalten (`content_vault.json`)**:
   - Bewährtes Starterpaket für echten Autoritätsaufbau und die ersten Follower.
   - Alltagstipps (25), Lifestyle & Identifikation (25), Umfragen & Spiele (25), Dialoge (25).

3. **🖥️ Glassmorphism Desktop-Web-Dashboard (`http://localhost:3500`)**:
   - Modernes Dark-Mode-Design mit transparenten Glaselementen.
   - **Automatische 8-Sprachen-Übersetzung (i18n)**: Browsersprachenerkennung & Sprachwechsler.
   - 6 Module: Dashboard, Karten, Kommentare, Konto, Einstellungen, Konsole.

4. **🛡️ Anti-Bot-Schutzschild & Menschenähnliche Steuerung**:
   - Strenge tägliche Sicherheitslimits (max. 40 Follows, 30 Kommentare pro Tag).
   - Natürliche variable Tippgeschwindigkeit (35~110ms) und dynamische Pausen.

5. **🔥 Affiliate-Deals & Offizielle Graph API-Unterstützung**:
   - Automatische Partnerlink-Erstellung und getrennte Bereitstellung von Text und Link.
   - Hybride Unterstützung für Meta Graph API und authentische Playwright-Chrome-Sitzungen.

## 🚀 Schnellstart

### 1. Voraussetzungen
- Node.js 18 oder höher
- Google Chrome Browser

### 2. Klonen & Installieren
```bash
git clone https://github.com/nerin81-netizen/threads-affiliate-automation.git
cd threads-affiliate-automation
npm install
```

### 3. Umgebungsvariablen einrichten
```bash
cp .env.example .env
```

### 4. Starten
```bash
npm start
# oder Doppelklick auf start_dashboard.bat
```
Öffnen Sie `http://localhost:3500` im Browser. (Wird automatisch an Ihre Browsersprache angepasst).
