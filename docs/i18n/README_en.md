## 📌 Key Features

1. **💬 Rapport & AI Comment Engine (`scripts/rapport_engine.mjs`)**:
   - Understands native social slang and informal conversational tones.
   - Generates 3 contextual styles (Deep Empathy, Witty Banter, Warm Healing).
   - Real-time keyword extraction & automated safe engagement pipeline.

2. **📦 30-Day 100 Killer Content Vault (`content_vault.json`)**:
   - Proven starter pack designed to build authentic authority and initial follower base.
   - Life Hacks (25), Relatable Lifestyle (25), Polls & Balance Games (25), Authentic Q&A (25).

3. **🖥️ Glassmorphism Desktop Web Dashboard (`http://localhost:3500`)**:
   - Sleek modern dark mode with translucent glassmorphic UI layers.
   - **8-Language Auto-Translation (i18n)**: Automatic browser locale detection & one-click language switcher.
   - 6 Subpages: Dashboard, Card Studio, Rapport & Comments, Account, Settings, and Live Console.

4. **🛡️ Anti-Bot Defense Shield & Human Emulation**:
   - Strict daily safety thresholds (40 follows, 30 comments per day).
   - Human-like typing cadence (35~110ms) and dynamic cooldown jitter.

5. **🔥 Affiliate Deals & Official Graph API Support**:
   - Automated product collection and revenue share link generation.
   - Separates body hooks from commission links in first comments.
   - Hybrid support for Meta Threads Graph API and authentic Playwright Chrome sessions.

## 🚀 Quick Start

### 1. Prerequisites
- Node.js 18 or higher
- Google Chrome browser

### 2. Clone & Install
```bash
git clone https://github.com/nerin81-netizen/threads-affiliate-automation.git
cd threads-affiliate-automation
npm install
```

### 3. Configure Environment Variables
Copy `.env.example` to `.env` and fill in your credentials:
```bash
cp .env.example .env
```

### 4. Launch Dashboard
```bash
npm start
# or double click start_dashboard.bat
```
Open `http://localhost:3500` in your browser. (The dashboard automatically adapts to your browser language: EN, KO, JA, ZH, ES, DE, FR, PT).
